### F-001: `ferry-release/PRIVACY.md` links to private `ThienNg65/ferry` repo and lags behind `ferryssh.com/privacy`
- **Affected component:** `ThienNg65/ferry-release` `PRIVACY.md:3-8,33` (and identical `ThienNg65/ferry` `PRIVACY.md`, SHA `9c47b6fb984ce107d0d987d3ce1b9806ae77e541`).
- **Evidence / Reproduction:** `PRIVACY.md:6` reads `**Contact:** [GitHub Issues](https://github.com/ThienNg65/ferry/issues) · [GitHub Security Advisories](https://github.com/ThienNg65/ferry/security)`, which 404s for public users because `ThienNg65/ferry` is private. `PRIVACY.md:8` still states `open-source (MIT-licensed)` while `ferry-release/README.md:57` and `ferryssh.com/terms` state that historical source releases were MIT-licensed. `PRIVACY.md` is also at Policy Version `1.0` (`2026-11-14`) whereas `ferry-website/app/pages/privacy.vue` is at `1.1` (`2026-11-23`), and `.github/scripts/publish-public-release.mjs` only syncs `README.md`, `CHANGELOG.md`, and `assets/*.jpg`.
- **Root cause & impact:** `PRIVACY.md` was not updated or included in public-repo sync when `ThienNg65/ferry` became private and `ferryssh.com/privacy` moved to v1.1.
- **Remediation:** Update `PRIVACY.md` contact links to `https://github.com/ThienNg65/ferry-release/issues`, align licensing wording with `ferry-release/README.md`, sync policy version `1.1`, and consider syncing `PRIVACY.md` via `publish-public-release.mjs`.

### F-002: PR `#165` `ferry-pro` proxy path skips `history` / `workspaceSignal` bounds applied to Gemini path
- **Affected component:** `ThienNg65/ferry` PR `#165` (`c7edb32f`), `src/main/companion/AiCompanionService.ts:423-431` vs `lines 147-184`.
- **Evidence / Reproduction:** In `AiCompanionService.chat()`, the `gemini` branch builds `input` via `buildUserInput()` (`MAX_HISTORY_TURNS = 6`, 1,000 chars/turn, `logPath` 256 chars, `logSnippet` 2,500 chars, `monitorSummary` 1,500 chars). The `ferry-pro` branch serializes `history: request.history ?? []` and `workspaceSignal: request.workspaceSignal` directly without slicing or per-turn length capping.
- **Root cause & impact:** Unbounded `history` payloads from an IPC caller are forwarded directly to the Ferry Pro proxy.
- **Remediation:** Apply the same history normalization/truncation helper to both `gemini` and `ferry-pro` request payloads.

### F-003: PR `#165` natural-language credential regex stops at punctuation characters
- **Affected component:** `ThienNg65/ferry` PR `#165` (`c7edb32f`), `src/renderer/src/utils/companionPrivacy.ts:60`.
- **Evidence / Reproduction:** Rule 5 uses `(?:"[^"]+"|'[^']+'|[A-Za-z0-9._~+/=-]+)` for unquoted natural-language credentials, unlike Rule 4 (`[^\s,;]+`). An unquoted secret containing `@`, `!`, `#`, `$`, `%`, `^`, `&`, or `*` (e.g., `my password is p@ss!w0rd`) stops matching at the first punctuation character and leaves the remainder unredacted.
- **Root cause & impact:** Character class excludes common password special characters.
- **Remediation:** Expand unquoted token matching to non-whitespace characters (stripping trailing sentence punctuation) and add a regression test with special characters.

### F-004: PR `#165` `companionVersion.ts` prerelease comparison still uses `localeCompare()`
- **Affected component:** `ThienNg65/ferry` PR `#165` (`c7edb32f`), `src/renderer/src/utils/companionVersion.ts:32`.
- **Evidence / Reproduction:** `return pa.prerelease.localeCompare(pb.prerelease)` sorts `beta.10` before `beta.2`. Previously reported on `a09884d`; acknowledged in PR `#165` description ("Remaining Known Finding") while PR remains Draft.
- **Remediation:** Implement SemVer 2.0 dot-separated identifier comparison (numeric numerically, alphanumeric lexically) with regression tests for `beta.2` vs `beta.10`.
